# 项目案例回放

直接用浏览器打开 **`index.html`**。无需安装 Python、启动服务器、连接数据库或填写 API Key。断网也可以切换案例和查看证据；只有主动点击原始来源链接才会访问外部网站。

页面包含四个案例：岗位摘要检索、筛选后无证据拒答、评估保存与复查、一条带页码的 PDF 模型回答。前三例由当前项目代码离线运行生成；PDF 例为此前真实模型调用的保存记录，日期单独标注。它们是案例回放，不接受任意新问题。

## 文件

- `index.html`：完整页面，样式、程序和结果都已放在文件内，可以单独复制。
- `replay.json`：页面对应的结果、执行检查与代码摘要，便于阅读核对。
- `selected_sources.json`：仅本演示所需的两条历史岗位摘要与一条 PDF 问答节选。
- `page.html`：页面模板，供开发者修改外观；查看演示请打开 `index.html`。

## 数据说明

两条岗位摘要采集于 2026-08-20，来源链接指向百度招聘官网。它们是项目整理的历史摘要，不是完整职位原文，不能证明岗位现在仍开放。演示能力清单是明确标注的例子，不包含用户的个人简历。

PDF 回答来自 2026-09-09 对 ESP32-S3-WROOM-2 技术规格书的真实模型调用，仅展示支持回答的一段必要原文和页码。原文版权归原权利人；没有附上完整 PDF。完整研究语料、原始向量索引、私有配置和实际业务数据库都不在演示中。

页面里显示的内容也可以被下载。当前检查能拦截常见手机号、邮箱、密钥形态和本机路径，不是对任何输入都有效的隐私识别系统。

## 开发者重新生成

在 `projects/research_assistant` 安装 `requirements-backend.txt`，然后运行：

```bash
python demo_replay.py
python -m unittest test_demo_replay
```

生成器只读这个目录的选定材料，不读取研究 CSV、PDF 原件、完整向量库或密钥。岗位案例复用现有检索与 GroundedRAGService；后端案例通过现有 SQLAlchemy/Alembic/Repository/EvaluationService 在新的本机 SQLite 中执行。生成时不允许网络连接，也不会重新执行历史 PDF 模型请求。

本地生成记录放在根目录的 `output/replay-runtime/`，不进入公开代码包。`replay.json` 保留结果和源码摘要；重新生成会刷新执行时间和本机测量值，不应拿小样本延迟当作生产性能。

完整项目使用自己的数据的方法见源码包根目录 README。浏览回放不需要执行以上命令。
